# Connectivity — IGCSE ICT

Interactive lesson for Pearson Edexcel International GCSE ICT, **Unit 2 Connectivity**: Chapter 4 Digital communication and Chapter 5 Networks.

Each section is explained step by step with an interactive simulation, followed by the book's **activities** (where the book has them) and a short auto-marked **✓ Check**. Each part ends with a **test** (multiple choice + exam-style questions with mark schemes).

**Part A · Digital communication**

1. Bandwidth, buffer and latency — water-pipe bandwidth, streaming buffer, ping simulator, lag game → Activities → ✓ Check
2. Factors that affect speed — transfer method, interference, shielding, blockages, distance → ✓ Check
3. Device to device and networks — Table 4.1, LAN, WAN, PAN/WPAN, tethering, “which network?” → ✓ Check
4. How digital devices communicate — satellite (GPS, DVB-S, phones, military), broadcast (analogue, DVB-T, DAB), wired connections → ✓ Check
5. Wireless communication — Wi-Fi, Bluetooth pairing, 3G/4G, infra-red, NFC → Activities (incl. auto-marked Table 4.5) → ✓ Check
6. Wired vs wireless and broadband — Table 4.6 balance, broadband, mobile broadband, cellular networks → ✓ Check
7. Test Part A

**Part B · Networks**

8. Identifying devices — network OS, IPv4/IPv6, DHCP, MAC addresses, device names, packets and switches → Activities → ✓ Check
9. Components — cables, slowest part, access points, switches, gateways, routers, boosters, servers, print queue, **network builder** (chapter question 11) → ✓ Check
10. Connecting to the internet — ISP, browser vs search engine, filter software (blacklist/whitelist) → ✓ Check
11. Peer-to-peer and client-server — benefits of LANs, access rights, central backup, roaming profiles → Activities → ✓ Check
12. Securing data — logins, firewall, Caesar cipher, symmetric and public key, WEP/WPA, VPN, rights, logs, backups → Activities → ✓ Check
13. Test Part B · Key terms (searchable)

**Progress that students can share and resume**

- Everything is saved automatically in the student's browser (`localStorage`): sections seen, check scores, activity answers and test answers. A test can be finished in another lesson.
- **My progress** (top of the page) shows the percentage completed, and has **Copy my progress** / **Download .txt**: a report for the teacher with scores, activity answers and written test answers.
- **Progress code**: students can copy a code (or save it as a file) and paste it on another device to carry on there.
- When a student comes back, a “Welcome back” box offers to continue where they left off.
- Nothing is sent to a server.

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F), Help (?). Each scene has its own URL, e.g. `#security` or `#check-security`.

Plain HTML, CSS and JavaScript — no build step. All simulations are original; the people, companies and websites are made up, except examples taken from the book.
